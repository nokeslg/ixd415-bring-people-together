# Analytics (Plausible)

We use [Plausible](https://plausible.io) to count visitors toward our 100-tester goal. Shared by the whole team, so it lives here rather than in anyone's folder.

- **Site tracked:** https://sqku.pages.dev
- **Dashboard access:** log in at [plausible.io](https://plausible.io). Loudon set up the site; Madi is a team member too. Anyone else who needs it, ask Loudon to invite you (Site settings → People).
- **Snippet:** Plausible has to load inside each app's page, so the tracking code stays in the app itself. It's in the `<head>` of:
  - [Side_Quest/public/index.html](../Side_Quest/public/index.html): Side Quest, the version published at sqku.pages.dev from Nov 25 on.
  - [Loudon/Open_Seat_V3/public/index.html](../Loudon/Open_Seat_V3/public/index.html): Open Seat V3, what sqku.pages.dev showed before that.
- **Screenshots:** anyone on the team can add one. Dashboard captures go in this folder, named `YYYY-MM-DD_plausible_analytics.webp`.
  - [2026-11-23](2026-11-23_plausible_analytics.webp): first visitor
