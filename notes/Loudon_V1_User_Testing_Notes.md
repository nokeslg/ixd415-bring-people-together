# Loudon: Open Seat V1 user testing (Week 2)

I tested the first version of Open Seat ([Loudon/Open_Seat_V1](../Loudon/Open_Seat_V1/)) with 5 people. I had something come up with work, so each test was one-on-one, one person at a time. That means nobody got to see another person join their table or group, which is a big part of what the app is for.

## Key takeaways across all 5

1. **The app felt empty when testing alone.** Users 2 and 4 both tried Spin first, but there were no open seats, so they tried a random group, and that couldn't form with just one person. User 5 also went into a random lobby and asked if that was all they had to do. Nobody got to the actual "meet someone" moment. Next time I need to test with multiple people at the same time.
2. **Group searching needs a timeout/countdown.** User 4 asked if there would be a timeout if the group search lasted too long. Right now, if fewer than 3 people are waiting, it just waits forever. This could be similar to things like Pokemon Go, where lobbies are locked to a 120 sec timer so there aren't people AFK in the lobby.
3. **Safety: people want to choose who they're meeting.** User 1 was a woman and said that if she got randomly paired into a group of ALL men, she likely wouldn't feel super comfortable or safe. This was a super valid critique, and I'll likely take it into account with pronouns/gender or something similar.
4. **Finding each other is the biggest question.** User 3 asked about location and how to find the person, and brought up that some sort of navigation/maps could be a good way to find the others. User 5 asked about indicators that show a person is there. Right now the only person with any description ("how to find me") is the one who opens the table, so everyone joining should get a brief note about who they are/what they look like too.
5. **The Lunch/Study switch was confusing at first.** User 2 expected the entire menu to change, not just the tab. It wasn't totally clear that it was just a tab.
6. **Emojis as profiles worked.** Users liked having an emoji stand in for a profile because it helps with anonymity.
7. **"I'm here" wasn't obvious for everyone.** User 1 took a sec to understand she needed to press it. User 3 pressed it right away.
8. **The live parts were favorites.** User 3 really liked the table chat, and User 5 really liked the live lobby view.
9. **Overall, the idea landed.** User 1 thought it was very useful and could see herself using it. User 5 thought it was very intuitive and could see themselves using it because it made meeting people into a game of sorts. User 2 liked the idea but thought the main screen was confusing at first.

## Things to change for V2

- Let people choose whether they're meeting women, through pronouns/gender or a similar option.
- Add a visible countdown while searching for a group, so it ends instead of waiting forever.
- Help people find each other: maps/navigation, or at least a floor/area plus the "how to find me" hint.
- Let everyone add a brief note about who they are/what they look like, not just the person who opens the table, plus an indicator that shows when someone is actually there.
- Make Lunch vs. Study clearer, so it's obvious what changes when you switch.
- Show seats at a table vertically.
- Make "I'm here" more obvious.
- Test with several people at once, so tables and random groups actually fill.
